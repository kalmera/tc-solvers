# LLM-s used in the project

OpenAI GPT-5.4, GPT-5.5, GPT-5.6 Sol, and GPT-6 Astra were used to develop the final solver algorithms, formalizations and proofs. GPT-5.6 Sol and GPT-6 Astra were used in experimental evaluation and final preparation. The project would not have been possible without those tools.
